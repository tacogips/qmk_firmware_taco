Ergo68 `tacogips` keymap

Build:

```sh
make yushakobo/ergo68:tacogips
```

Flash:

```sh
make yushakobo/ergo68:tacogips:avrdude
```

Switch compatibility:

- Ergo68 is for Cherry MX compatible switches.
- Gateron KS-33 Low Profile 2.0 does not fit Ergo68.
- If the plastic locating pins do not enter the PCB holes, the switch is not compatible.
